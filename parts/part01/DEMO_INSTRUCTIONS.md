# 📌 Part 1 of 10 – Project Setup & Landing Page

## What This Part Demonstrates
- React + TypeScript + Vite project setup
- Tailwind CSS and custom UI design system (glassmorphism, gradients)
- Navbar component with navigation links
- Hero section with animated text and badges (Framer Motion)
- Feature Cards grid (6 cards: ATS Optimization, Content Analysis, Format Check, etc.)
- Animated background effects
- CTA section
- Footer
- **Upload feature is intentionally disabled** — coming in Part 2

## How to Run

### Step 1 – Install dependencies
```bash
cd resu-score-frontend
npm install
```

### Step 2 – Start the dev server
```bash
npm run dev
```

### Step 3 – Open in browser
Visit: http://localhost:5173

## What to Show the Faculty
1. The landing page loads with smooth animations
2. All 6 feature cards appear with staggered animation
3. The glassmorphism design (glass cards, gradient text)
4. The navbar with ResuScore branding
5. The "Upload Feature – Coming in Part 2" placeholder
6. Responsive layout (can resize the window)

## Notes
- No backend is needed for this part
- node_modules is excluded — run `npm install` before the demo
